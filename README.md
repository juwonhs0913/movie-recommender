## Movie Recommender (영화 추천 프로그램)

사용자, 영화, 평점 데이터를 바탕으로 사용자 맞춤형 영화를 추천하는 C++ 기반의 프로그램입니다. 협업 필터링(Collaborative Filtering) 알고리즘을 사용하여 대상 사용자와 유사한 평가 성향을 가진 다른 사용자들의 데이터를 분석하고, 아직 시청하지 않은 최적의 영화를 추천합니다.

---

## 프로젝트 개요
- **주요 기능:**
  - 영화, 사용자, 평점 데이터의 추가, 검색 및 관리
  - 다중 조건 정렬 기능 (평점순, 제목 가나다순, 개봉 연도 최신순, ID순)
  - 통계 분석 기능 (전체 평균 평점, 장르별 평균 평점, 최고 인기 장르 도출)
  - 협업 필터링 기반 사용자 맞춤형 영화 추천 알고리즘
  - CSV 파일 기반의 데이터 로드 및 저장 (데이터 영속성 보장)

**요구사항:** g++ (C++17 이상)

## 클래스 구조

```
로직 계층
├── BaseManager (abstract)      - loadFromFile / saveToFile / size 인터페이스 정의
│   ├── MovieManager            - Movie 객체 관리
│   ├── UserManager             - User 객체 관리
│   └── RatingManager           - Rating 객체 관리
│
└── Recommender (추천 엔진)     - MovieManager / UserManager / RatingManager 참조

매니저 계층
├── MovieManager  →  Movie  (데이터 계층)
├── UserManager   →  User   (데이터 계층)
└── RatingManager →  Rating (데이터 계층)

데이터 계층
├── Movie
├── User
└── Rating
```

- **BaseManager** : 순수 가상 함수(`loadFromFile`, `saveToFile`, `size`)를 선언하는 추상 클래스. 세 매니저 클래스가 상속받아 공통 인터페이스를 통일한다.
- **Recommender** : 세 매니저를 레퍼런스로 주입받아 데이터에 접근하며, 추천 로직만 단독으로 담당한다.
- **매니저 계층** : 각 도메인 객체(Movie / User / Rating)의 컬렉션을 소유하고 CRUD 및 파일 I/O를 처리한다.
- **데이터 계층** : 단일 도메인 엔티티를 표현하며, 비즈니스 로직을 포함하지 않는다.

## 확장 기능

### 추천 흐름 (Recommender)

사용자 ID를 입력하면 아래 순서로 추천 결과를 반환한다.

```
1. 대상 사용자의 평점 목록 조회
   - 평점 데이터 없음 → 전체 Top N 폴백 반환

2. 유사 사용자 탐색 (findSimilarUsers)
   - 모든 타 사용자와 유사도 계산
   - 유사도 = 공통 시청 영화 수 × 10 - 평점 차이 합계
   - 유사도 > 0 인 사용자만 추출, 상위 5명 선택
   - 유사 사용자 없음 → 전체 Top N 폴백 반환

3. 후보 영화 점수 계산 (calculateCandidates)
   - 대상 사용자가 아직 보지 않은 영화만 대상
   - 가중 평균 점수 = Σ(유사도 × 평점) / Σ(유사도)

4. 상위 N편 추출 (extractTopN)
   - 가중 평균 점수 내림차순 정렬 후 상위 N개 ID 반환
```

### 통계 기능 (MovieManager::showStatistics)

메뉴 10번에서 진입하는 서브메뉴로, 세 가지 통계를 제공한다.

- **전체 평균 평점** : 등록된 모든 영화의 평균 평점을 `std::accumulate`로 계산한다. 영화 데이터가 없으면 `std::runtime_error` 예외를 발생시킨다.
- **장르별 평균 평점** : 장르를 키로 평점 합계와 건수를 집계한 뒤 평균을 산출한다. `std::max_element`로 평점이 가장 높은 인기 장르를 함께 출력한다.
- **Top N 영화** : 입력한 N에 대해 `std::partial_sort`로 상위 N편만 정렬하여 순위와 함께 출력한다. 전체 정렬이 아닌 부분 정렬을 사용하여 불필요한 연산을 줄인다.

### 정렬 기능 (MovieManager)

메뉴 4번에서 진입하는 서브메뉴로, 네 가지 기준을 지원한다. 모두 `std::sort`와 람다를 사용하며 `movies` 벡터를 제자리 정렬한다.

| 옵션 | 기준 | 정렬 방향 |
|------|------|-----------|
| 1 | 평균 평점 | 높은 순 |
| 2 | 제목 (가나다 / 알파벳) | 오름차순 |
| 3 | 개봉 연도 | 최신순 (내림차순) |
| 4 | 영화 ID | 오름차순 |

## 메뉴 구성

```
[ 영화 ]
   1. 영화 추가
   2. 제목으로 검색
   3. 전체 목록 출력
   4. 정렬 출력 (평점순 / 가나다순 / 최신순 / ID순)
[ 사용자 ]
   5. 사용자 추가
   6. 사용자 목록 출력
   7. 사용자 맞춤 추천 영화
[ 평점 ]
   8. 평점 입력
   9. 영화별 평점 보기
[ 통계 ]
  10. 통계 보기
   0. 저장 및 종료
```
